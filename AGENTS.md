# AGENTS.md — Ultix

Guidance for AI coding agents (and humans) working **inside this repository**.

Ultix is a personal, declarative **NixOS Stable flake** for two machines: a Zen 4 AMD desktop and an AMD/NVIDIA TUXEDO laptop. It layers:

- **Hyprland** (via UWSM) + **Noctalia v5** shell as the desktop session,
- **disko** (GPT → LUKS → Btrfs subvolumes) for declarative partitioning,
- an **impermanence** setup where `/` is wiped on every boot and `/persist` holds state,
- **Home Manager** + **sops-nix** (post-quantum Age encryption) for the user `fumoctl`,
- gaming (Steam, proton-cachyos/GE, gamescope, mangohud, lsfg-vk) and container/dev tooling (Docker, rootless Podman, `kind`, libvirt).

This file documents the architecture, conventions, and the traps that have actually bitten this config. **Read it fully before editing.** Every claim about evaluated values below was verified by evaluating the flake, not just by reading the source.

## 2. Hosts and targets

```text
nixosConfigurations.fumonix-desktop   # x86_64-linux, Ryzen 7600X (Zen 4), AMD GPU
nixosConfigurations.fumonix-laptop    # x86_64-linux, TUXEDO, AMD iGPU + NVIDIA dGPU (PRIME offload)
```

| Aspect | `fumonix-desktop` | `fumonix-laptop` |
|---|---|---|
| System | **x86_64-linux** | **x86_64-linux** |
| Kernel | `linuxPackages_cachyos-lto-znver4` (fallback `linuxPackages_latest`) | `linuxPackages_xanmod` |
| GPU | AMD (`amdgpu` in initrd, `modesetting`, VA-API extras) | AMD `amdgpu` + NVIDIA (`modesetting` + `nvidia` open PRIME offload) |
| Kernel param | `amdgpu.runpm=0` | (none beyond defaults) |
| Secure Boot | Limine `secureBoot.enable = true` | `secureBoot.enable = false` |
| Extra | — | `hardware.tuxedo-drivers`, `hardware.tuxedo-rs` (+ `tailor-gui`), `programs.captive-browser` on `wlp98s0` |
| Hostname | `fumonix-desktop` | `fumonix-laptop` |
| State dir | `/persist` | `/persist` (same layout) |

Both hosts share users, the `/persist` layout, the container stack, the session, and the Home Manager profile. Put host-specific behaviour in `hosts/<host>/*.nix` — not in `hosts/*.nix` — unless it is genuinely universal.

> There is exactly one architecture (`x86_64-linux`) used for both hosts and for Home Manager. Do not introduce per-arch abstractions (aarch64 branches, `flake-utils.eachSystem`, etc.) unless explicitly asked.

## 3. Module wiring (how a host is assembled)

`flake.nix` builds both hosts through `mkHost`:

```nix
mkHost =
  hostModule:
  nixpkgs.lib.nixosSystem {
    inherit system;                       # x86_64-linux
    specialArgs = { inherit inputs; };    # every module can take `inputs`
    modules = [
      disko.nixosModules.disko
      home-manager.nixosModules.home-manager
      chaotic.nixosModules.nyx-cache      # adds the Chaotic cache substituter
      chaotic.nixosModules.nyx-overlay
      chaotic.nixosModules.nyx-registry
      hostModule                          # ./hosts/desktop or ./hosts/laptop
    ];
  };
```

`hosts/<host>/default.nix` imports, in order:

```nix
[ ../common.nix ../containers.nix ./containers.nix ./hardware-configuration.nix ./disko.nix ]
```

- `hosts/<host>/disko.nix` defines the full GPT → LUKS → Btrfs layout and disk `by-id` for that host.
- `hosts/common.nix` imports `[ ./impermanence.nix ./networking.nix ./desktop-env.nix ./gaming.nix ./packages.nix ]` (where `impermanence.nix` imports `inputs.impermanence.nixosModules.impermanence` and `desktop-env.nix` imports `inputs.noctalia.nixosModules.default`), and ends by wiring Home Manager:

```nix
home-manager = {
  useGlobalPkgs = true;                 # HM packages come from the system pkgs (incl. overlays)
  useUserPackages = true;
  extraSpecialArgs = { inherit inputs; };
  users.fumoctl = import ../home;
  backupFileExtension = "backup";       # conflicting files become <file>.backup
};
```

`home/default.nix` imports:

```nix
[ ./secrets.nix ./noctalia.nix ./shell.nix ./apps.nix ./flatpak.nix ./mime.nix ]
```

where `secrets.nix`, `noctalia.nix`, and `flatpak.nix` import their respective flake Home Manager modules (`sops-nix`, `noctalia`, `nix-flatpak`).

**Rule of thumb:** a *system* option goes in `hosts/<domain>.nix` (shared) or `hosts/<host>/default.nix` (machine-specific). A *user* option goes in `home/*.nix`. System/admin/DE-plumbing packages go in `environment.systemPackages` (`hosts/packages.nix`, `hosts/desktop-env.nix`, `hosts/gaming.nix`, `hosts/containers.nix`); user GUI and terminal apps go in `home.packages` (`home/apps.nix`, `home/shell.nix`, `home/noctalia.nix`).

## 5. Storage, impermanence, and boot (the most delicate area)

### Disk layout (`hosts/<host>/disko.nix` — one full config per host)

```text
/dev/disk/by-id/<disk>                  GPT
├── ESP            1G   EF00  → vfat, mount /boot, umask=0077
└── luks           100%        → LUKS name "crypted" → btrfs (-f)
    ├── @            → /              compress=zstd,noatime   (RECREATED EMPTY ON EVERY BOOT)
    ├── @persist     → /persist       compress=zstd,noatime
    ├── @nix         → /nix           compress=zstd,noatime
    ├── @log         → /var/log       compress=zstd,noatime
    ├── @snapshots   → /.snapshots    compress=zstd,noatime
    └── @swap        → /.swapvol      noatime,nodatacow  + 32G swapfile
```

Current disk IDs (re-check with `ls -l /dev/disk/by-id/` before any reinstall):

- desktop (`hosts/desktop/disko.nix`): `/dev/disk/by-id/nvme-UPULTR7K-4TSD_UPULTR7K4T25090017`
- laptop (`hosts/laptop/disko.nix`): `/dev/disk/by-id/nvme-WD_Blue_SN5100_1TB_25453U402530`

disko references partitions by **label** at runtime (`/dev/disk/by-partlabel/disk-main-ESP`, `disk-main-luks`), so `hardware-configuration.nix` deliberately contains **no `fileSystems`** (disko generates them). Never duplicate `fileSystems` entries there.

The `@swap` subvolume is mounted at `/.swapvol`; swap lives at `/.swapvol/swapfile` (32G). On a fresh install you must `swapon` it manually before `nixos-install` (see README).

### Ephemeral root (`hosts/impermanence.nix`)

- `/nix`, `/persist`, and `/var/log` are marked `neededForBoot = true` and are mounted with `x-initrd.mount`.
- `boot.initrd.systemd.initrdBin = [ btrfs-progs coreutils gnused util-linux ]` makes those tools available in the systemd-based initrd.
- `boot.initrd.systemd.services.impermanence-clean-root` (`wantedBy = initrd.target`, `after = dev-mapper-crypted.device`, `before = sysroot.mount`):
  1. mounts the top-level subvolume (`subvolid=5`) of `/dev/mapper/crypted` at `/btrfs_tmp`,
  2. recursively deletes every nested subvolume of `@` (`btrfs subvolume list -o` piped through `sed`, sorted `-r`),
  3. deletes `@`,
  4. recreates an empty `@`,
  5. unmounts.

  Then the normal root mount (`sysroot.mount`, `subvol=@`) finds an empty root and impermanence bind-mounts everything back from `/persist`.

**`/etc/ly/save.txt` is persisted and `services.displayManager.ly` is the login manager.** If you replace the display manager, update the persistence list *and* `security.pam.services.ly.enableGnomeKeyring`, or the keyring will not auto-unlock.

### What survives a reboot

Declared in `environment.persistence."/persist"` (`hosts/impermanence.nix`, `hideMounts = true`, `allowTrash = true`):

- **System dirs**: `/etc/NetworkManager/system-connections`, `/var/lib/{AccountsService,NetworkManager,bluetooth,containers,docker,flatpak,libvirt,nixos,systemd,sbctl}`
- **System files**: `/etc/machine-id`, `/etc/ly/save.txt`
- **User `fumoctl` dirs**: Home XDG dirs (`Desktop`, `Documents`, `Downloads`, `Music`, `Pictures`, `Public`, `Templates`, `Videos`, `Projects`, `Games`, `Applications`), plus app state: `.config/{BraveSoftware,Code,VSCodium,equibop,dconf,gh,lsfg-vk,containers,Antigravity,MangoHud,xfce4,AmneziaVPN.ORG,"Podman Desktop",.android}`, `.local/share/{Steam,containers,direnv,flatpak,keyrings,Trash,dolphin,kxmlgui5,uv}`, `.local/state/noctalia`, `.local/bin`, `.cache/{bun,uv,ms-playwright}`, `.var/app` (Flatpak user data), mail/editor/game/toolchain dirs (`.thunderbird`, `.vscode*`, `.duckdb`, `.agents`, `.steam`, `.gemini`, `.m2`, `.gradle`, `.android`, `.bun`, `.cargo`, `.rustup`), and `{ .gnupg, .ssh }` with `mode = "0700"`.
- **User files**: `.config/zsh/.zsh_history`, plus symlinked KDE rc files (`.config/dolphinrc`, `.local/state/dolphinstaterc`, `.config/xdg-desktop-portal-kderc`, `.local/state/xdg-desktop-portal-kdestaterc`).

**If you add an app that stores state in `$HOME`, you must add its directory to `hosts/impermanence.nix`, or the state vanishes on the next reboot.** Watch for `.config/<NewApp>`, `.local/share/<NewApp>`, `.cache/<NewApp>`.

### Credentials (do not break)

- `users.mutableUsers = false` and `users.users.fumoctl.hashedPasswordFile = "/persist/passwords/fumoctl"`.
- The password hash lives **inside `/persist`** so it survives the root wipe. It is created manually at install time (README §4): `mkdir -p /mnt/persist/passwords`, `mkpasswd -m sha-512 | tee /mnt/persist/passwords/fumoctl`, `chmod 600`.
- **Never** commit a password hash, and never point `hashedPasswordFile` at a path outside `/persist`, or the user is locked out after the first boot.
- `home-manager.backupFileExtension = "backup"`: when a file is not yet a Home Manager symlink, HM moves it to `<name>.backup` before linking. Existing `.backup` files are expected and harmless.

## 7. Desktop stack (Hyprland + UWSM + Noctalia)

### Hyprland

- NixOS side (`hosts/desktop-env.nix`): `programs.hyprland = { enable = true; xwayland.enable = true; withUWSM = true; }`.
- HM side (`home/noctalia.nix`):

  ```nix
  wayland.windowManager.hyprland = {
    enable = true;
    systemd.enable = false;                 # UWSM manages session env & graphical-session.target
    portalPackage = null;                   # portals are managed system-wide in hosts/desktop-env.nix
    configType = "lua";                     # Hyprland 0.55+ native Lua config (liblua 5.5)
    extraConfig = builtins.readFile ./hyprland.lua;
  };
  ```

  This generates `~/.config/hypr/hyprland.lua` plus `~/.config/hypr/.luarc.json` (pointing the editor LSP at the Hyprland Lua stubs). **`home/hyprland.lua` is only picked up through this `readFile`** — renaming or moving it silently drops the entire window manager config, and switching to `settings` would emit the legacy format instead.

- `home/hyprland.lua` essentials:
  - `hl.env(...)` sets `QT_QPA_PLATFORMTHEME=kde` and cursor `Bibata-Modern-Ice` size 24 (`XCURSOR_*`/`HYPRCURSOR_*`).
  - `hl.on("hyprland.start", ...)` starts tray/session apps (`equibop -m` + `steam -silent`). Do **not** launch `noctalia` or call `dbus-update-activation-environment` here — UWSM finalizes the session environment and activates `graphical-session.target`, which starts `noctalia.service` cleanly (spawning `noctalia` manually causes `noctalia.service` to fail with `start-limit-hit`).
  - Monitors: one generic rule (`output = ""`, preferred, auto).
  - `general`: gaps 5/10, border 2, dwindle. `decoration`: rounding 12, blur on, opacity 0.94/0.88.
  - Input: `us`/`altgr-intl`, `lv3:ralt_switch` — keep in sync with `services.xserver.xkb`.
  - Layer rules: `noctalia` and `gtk-layer-shell` get blur; KDE portal dialogs float.
  - Binds: Super+Return (ptyxis), Super+E (dolphin), Super+B (brave), Super+Q close, Super+M exit (`uwsm stop` when active, else `hyprctl dispatch exit`), Super+F fullscreen, Super+Shift+V float, Super+P pseudo, Super+J togglesplit, Super+Space/V/S/comma (Noctalia launcher/clipboard/control-center/settings), Alt+Tab (`window-switcher`), Super+Shift+S / Super+Shift+Ctrl+S (Noctalia screenshots), focus/workspace binds 1–9, mouse drag/resize, XF86 media/brightness keys.
  - Prefer Noctalia IPC (`noctalia msg …`) for shell features in binds; see the noctalia input's `docs/user/ipc/` for the full command list.

### Noctalia (shell + bar)

- System (`hosts/desktop-env.nix`): `programs.noctalia = { enable = true; recommendedServices.enable = true; }`. The noctalia flake's NixOS module **disables** the nixpkgs noctalia module (`disabledModules`), and `recommendedServices` applies `mkDefault` for NetworkManager, Bluetooth, UPower, and power-profiles-daemon.
- HM (`home/noctalia.nix`):
  - `programs.noctalia = { enable = true; systemd.enable = true; settings = { theme.templates.builtin_ids = [ "gtk3" "gtk4" "kcolorscheme" ]; wallpaper.enabled = true; }; }`
    → generated `~/.config/noctalia/config.toml`, validated at build time by `noctalia config validate`.
  - `~/.config/noctalia/noctconf.toml` (symlink to `home/noctalia.toml`, set via `home.file`) holds the hand-written bar/widget/theme/plugin TOML. Noctalia reads **every `*.toml`** in `~/.config/noctalia/` alphabetically and merges them, so `config.toml` (Nix-declarative) and `noctconf.toml` (hand-edited) coexist. Keep `[plugins].enabled` in `noctalia.toml` alongside any custom plugin widgets (e.g. `elijaharch/wl-screen-mirror`) so `noctalia config validate home/noctalia.toml` passes standalone without warnings.
  - Runtime GUI overrides go to `~/.local/state/noctalia/settings.toml` (**persisted** via `.local/state/noctalia`) and **win over** the declarative config. If a declarative change "does nothing", check that file.
  - Service: `~/.config/systemd/user/noctalia.service`, `WantedBy/PartOf/After graphical-session.target`, with `X-Restart-Triggers` on the generated config.

### Theming & KDE/Dolphin glue

- GTK: `adw-gtk3-dark`, icon theme `breeze` (`kdePackages.breeze-icons`), cursor `Bibata-Modern-Ice` 24 (`home.pointerCursor` with gtk + hyprcursor).
- Qt: `qt.platformTheme.name = "kde"` + `QT_QPA_PLATFORMTHEME=kde`; `kdePackages.qt6ct` (HM) and system-wide KF6/Dolphin/Ark/thumbnailer plugins discovered via `QT_PLUGIN_PATH` / `QML2_IMPORT_PATH` in `home/noctalia.nix`.
- Extra HM packages for Noctalia hooks: `adw-gtk3` (theme lookup), `glib` (`gsettings`, used by the GTK apply hook).
- `kdeXdgMenus` and `kdePtyxis` in `hosts/desktop-env.nix` give Dolphin standalone XDG menu categories (without pulling `plasma-workspace` into the closure) and route "Open Terminal Here" (`TerminalApplication=kde-ptyxis` in `/etc/xdg/kdeglobals`) to Ptyxis.
- `documentation.man.cache` and `fonts.fontconfig.defaultFonts` (JetBrainsMono NF / Noto CJK JP) are set system-wide; fonts referenced in `hyprland.lua`/`noctalia.toml`/`shell.nix` must come from `hosts/desktop-env.nix`.

## 8. XDG portals (`hosts/desktop-env.nix` — read the inline note before touching)

```nix
xdg.portal = {
  enable = true;
  wlr.enable = false;
  extraPortals = [ pkgs.xdg-desktop-portal-hyprland pkgs.xdg-desktop-portal-gtk pkgs.kdePackages.xdg-desktop-portal-kde ];
  config.common = { default = [ "gtk" ]; "org.freedesktop.impl.portal.FileChooser" = [ "kde" ]; "org.freedesktop.impl.portal.AppChooser" = [ "kde" ]; };
  config.hyprland = { default = [ "hyprland" "gtk" ]; "org.freedesktop.impl.portal.FileChooser" = [ "kde" ]; "org.freedesktop.impl.portal.AppChooser" = [ "kde" ]; }; # NOT just ["hyprland"]
};
```

The `hyprland` section overrides `common` for **all** interfaces when `XDG_CURRENT_DESKTOP=Hyprland`. The Hyprland portal only implements Screenshot/ScreenCast/GlobalShortcuts, so `gtk` must stay in the list, or `org.freedesktop.portal.Settings` disappears and libadwaita apps (Ptyxis) always render in light mode. Preserve the inline comment in `hosts/desktop-env.nix`. `FileChooser` and `AppChooser` are routed to `kde` (`xdg-desktop-portal-kde`) for the Dolphin-backed file picker, and `wayland.windowManager.hyprland.portalPackage = null` in `home/noctalia.nix` prevents Home Manager from overriding `NIX_XDG_DESKTOP_PORTAL_DIR`.

Session env vars (`environment.sessionVariables`): `NIXOS_OZONE_WL=1`, `MOZ_ENABLE_WAYLAND=1`, `XDG_CURRENT_DESKTOP/SESSION_DESKTOP=Hyprland`, `XDG_SESSION_TYPE=wayland`, `QT_QPA_PLATFORM="wayland;xcb"`, `QT_WAYLAND_DISABLE_WINDOWDECORATION=1`, `GDK_BACKEND="wayland,x11,*"`, `SDL_VIDEODRIVER=wayland`, `CLUTTER_BACKEND=wayland`, `DICPATH="/run/current-system/sw/share/hunspell"`.

## 9. Networking, DNS, VPN, firewall (`hosts/networking.nix` + `hosts/common.nix`)

- `networking.nftables.enable = true`; `firewall.enable = true`, `checkReversePath = "loose"`, trusted interfaces `tun0`, `tun2`, `amn0` (+ `lo`).
- NetworkManager with `dns = "systemd-resolved"`, ignoring DHCP-provided DNS (v4/v6), stable-temporary MACs, IPv6 privacy `2`, random scan MAC.
- `services.resolved` (systemd, **not** unbound — `services.unbound.enable = false`): DNSSEC on, DNSOverTLS on, AdGuard DNS primary, Quad9 + Mullvad fallbacks, `Domains = [ "~." ]`.
- `programs.amnezia-vpn` (from the unstable overlay) is the VPN. WireGuard/OpenVPN trust is expressed via `trustedInterfaces`, not `allowedUDPPorts`.
- `services.tzupdate.enable = true` (`hosts/common.nix`) — **this overrides `time.timeZone`.** `common.nix` sets `time.timeZone` via `lib.mkDefault "America/Argentina/Buenos_Aires"`, but the evaluated `config.time.timeZone` is `null` and the machine follows the IP-derived zone. Do **not** rely on `time.timeZone`; if a fixed zone is required, disable tzupdate and set the option unconditionally.
- `programs.captive-browser` is laptop-only (`hosts/laptop/default.nix`), bound to `wlp98s0`.

## 10. Virtualisation and containers (`hosts/containers.nix`)

`hosts/containers.nix` (shared) + `hosts/<host>/containers.nix` (host-specific, merged by the module system):

- **Docker** (rootful, `autoPrune.enable = true`) and **Podman** (rootless, `defaultNetwork.settings.dns_enabled = true`) are both enabled.
- **Critical invariant:** `virtualisation.podman.dockerCompat = false` and `dockerSocket.enable = false`. Never enable them — the `docker` CLI and `/var/run/docker.sock` must keep pointing at dockerd (verified: the `oci-containers` backend is `podman`, while Docker owns the real socket).
- `virtualisation.containers.storage.settings.storage.driver = "overlay"`.
- `virtualisation.oci-containers.backend = "podman"` with shared container `yugabyte` (`docker.io/yugabytedb/yugabyte:latest`, `autoStart = false`, `--network=host`, volume `yugabyte-data:/home/yugabyte/var:Z`, runs as user `fumoctl`). It was fiddly to get right — don't change `cmd`/`extraOptions` without running it.
- Tools: `kind`, `kubectl`, `helm`, `k9s`, `skopeo`, `dive`, `podman-desktop`, `docker-compose`, `podman-compose`, `fuse-overlayfs`, `shadow` (newuidmap/newgidmap), plus `distrobox` in `hosts/packages.nix`.
- **libvirt** (QEMU/KVM, `runAsRoot = true`, `swtpm` for TPM, `virtiofsd`) + `virt-manager` + `spice-vdagentd`. Emulators and external Flutter/Qt binaries rely on `programs.nix-ld.libraries` in `hosts/packages.nix`.

When adding a container: shared/common services go in `hosts/containers.nix`; per-machine ones go in `hosts/<host>/containers.nix` using the commented template. Keep `autoStart` explicit.

## 11. Nix daemon settings and local commands

```nix
nix.settings = {
  experimental-features = [ "nix-command" "flakes" ];
  trusted-users = [ "root" "@wheel" ];
  auto-optimise-store = lib.mkDefault true;
  substituters = [ cache.nixos.org noctalia.cachix.org nyx-cache.chaotic.cx ];
  trusted-public-keys = [ ... ];
};
```

NixOS appends to `substituters` rather than replacing the default, so `/etc/nix/nix.conf` lists `cache.nixos.org` and `nyx-cache` **twice**. That is expected and harmless — don't add `mkForce` just to de-duplicate.

```bash
# Build/switch
sudo nixos-rebuild switch --flake .#fumonix-desktop
sudo nixos-rebuild switch --flake .#fumonix-laptop
sudo nixos-rebuild boot   --flake .#fumonix-desktop   # apply at next boot (safer for initrd/impermanence changes)

# Evaluate only (fast sanity check)
nix eval .#nixosConfigurations.fumonix-desktop.config.system.build.toplevel.drvPath

# Single option
nix eval --raw .#nixosConfigurations.fumonix-desktop.config.services.displayManager.defaultSession

# Home Manager option value
nix eval --json .#nixosConfigurations.fumonix-desktop.config.home-manager.users.fumoctl.programs.git.signing

# Formatting / editor tooling
nixfmt $(git ls-files '*.nix')
nixd          # LSP, installed system-wide

# Update one input
nix flake update noctalia
```

> If `nix eval` fails with `attempt to write a readonly database (... fetcher-cache-v4.sqlite)`, the sandboxed/agent environment has a read-only XDG cache. Work around it with a private cache dir: `XDG_CACHE_HOME=$(mktemp -d) nix --offline eval …`. Also remember to `git add -N <new-file>` before `nix eval` whenever creating new files in a flake.

## 12. Known quirks and traps (do not "fix" blindly)

1. **`flake.lock` revision vs branch name:** The `nixpkgs` input URL points to `nixos-26.05`. If a task is about pinning/release hygiene, raise it; otherwise leave `flake.lock` alone unless `flake.nix` inputs changed.
2. **`programs.noctalia.systemd` (system) is not enabled** — only the HM user service (`noctalia.service`) is. Don't assume a system-level noctalia unit exists.
3. **UWSM owns the Wayland systemd session:** `programs.hyprland.withUWSM = true` (NixOS) paired with `wayland.windowManager.hyprland.systemd.enable = false` (HM) ensures UWSM brings up `graphical-session.target` and starts `noctalia.service` once cleanly. Never re-enable HM's `hyprland.systemd.enable` or spawn `noctalia` directly in `hyprland.lua`.
4. **Two Noctalia config sources:** `~/.config/noctalia/config.toml` (from `programs.noctalia.settings` in `home/noctalia.nix`) and `~/.config/noctalia/noctconf.toml` (from `home/noctalia.toml`) are merged by Noctalia. Before editing a key, check which of the two (or `~/.local/state/noctalia/settings.toml`) owns it.
5. **`home/shell.nix` SSH config uses an `onChange` hook:** `~/.ssh/config_source` is copied via `install -m 600` to `~/.ssh/config` because HM cannot produce a `0600` symlink.
6. **Git commit signing is enforced** (`signing.key = "35FAC098F119E8FA"`, `signByDefault = true`, tags signed). `sops-import-pgp.service` (`home/secrets.nix`) imports the decrypted PGP key automatically after `sops-nix.service`. Commits made without the key/`gpg-agent` will fail by design.
7. **Flatpak is managed declaratively in `home/flatpak.nix`** via `inputs.nix-flatpak.homeManagerModules.nix-flatpak` (packages, daily update timer, and `services.flatpak.overrides` for GTK/icon `/nix/store` access, Bottles `home`, and OBS Qt env unsets), while `services.flatpak.enable = true` in `hosts/desktop-env.nix` enables the system daemon/portals. `.var/app` and `~/.local/share/flatpak` are persisted.
8. **`home.activation` hooks that interpolate `pkgs` must run after `writeBoundary`** (via `lib.hm.dag.entryAfter [ "writeBoundary" ]`).
9. **`hardware-configuration.nix` is generated** by `nixos-generate-config`; hand-edit only the kernel-module lists and never re-add `fileSystems` (disko owns them).
10. **`dotfiles/wallpaper.png` is unused**; Noctalia wallpapers are managed by the shell (`.local/state/noctalia` is persisted).
11. **`system.stateVersion = "26.05"` and `home.stateVersion = "26.05"`** — do **not** bump these to silence warnings; they gate migrations.
12. **`pkgs.unstable` is an overlay attribute, not `pkgs.nixpkgs-unstable`.** Don't import `inputs.nixpkgs-unstable` inside modules; use `pkgs.unstable.*`.
13. **No noctalia plugin mirror packaging:** the `elijaharch/wl-screen-mirror` plugin is fetched at runtime by Noctalia (community source), so its state lives under `~/.local/state/noctalia` (persisted).

## 13. Conventions for changes

**Style**

- Nix code is formatted with `nixfmt` (RFC-style). Run `nixfmt --check $(git ls-files '*.nix')` after any edit.
- Keep module headers minimal to the arguments actually used (`{ config, lib, pkgs, inputs, ... }:` or the needed subset); `inputs` is always available via `specialArgs` / `extraSpecialArgs`.
- Section headers are `# --- Foo ---`. Explanatory comments (especially the portal, keyring, UWSM, and podman ones) explain *why* and must be preserved when editing nearby lines.
- Prefer `lib.mkDefault` for anything a host may override (kernel, secure boot, timezone, Bluetooth, UPower, PPD).
- Never hard-code the absolute path of a package binary in HM activation or scripts — use `${pkgs.foo}/bin/foo` or `lib.getExe`.

**Adding things**

| Goal | Where |
|---|---|
| System-wide CLI/admin/dev tool | `environment.systemPackages` in `hosts/packages.nix` |
| Desktop/DE/Dolphin helper | `hosts/desktop-env.nix` |
| User GUI or productivity app | `home/apps.nix` (`home.packages` or `programs.*`) |
| User shell/terminal tool | `home/shell.nix` |
| Unstable app | prefix with `unstable.` |
| System service | `hosts/<domain>.nix` (shared) or `hosts/<host>/default.nix` (host-specific) |
| User service / dotfile | `home/*.nix` (`systemd.user.services`, `home.file`, `xdg.configFile`) |
| New app with `$HOME` state | also add the dir to `environment.persistence."/persist".users.fumoctl.directories` in `hosts/impermanence.nix` |
| New OCI container | `hosts/containers.nix` (shared) or `hosts/<host>/containers.nix` |
| New Flatpak or override | `services.flatpak.{packages,overrides}` in `home/flatpak.nix` |
| New Hyprland bind/rule | `home/hyprland.lua` (Lua `hl.` API) |
| New bar widget / palette | `home/noctalia.toml` |
| New MIME association | `xdg.mimeApps.defaultApplications` in `home/mime.nix` |
| New SOPS secret | `secrets/secrets.yaml` + `home/secrets.nix` |

**Committing**

- Commit messages here are short and often joking ("yugabyte final fix geez", "update + vscodium"). Match the terse style; do **not** add "Generated with …" trailers or co-author lines unless asked.
- Commit `flake.lock` whenever you change `flake.nix` inputs.
- Conventional-commit prefixes are **not** used here.


```bash

  --mode disko --flake github:fumoctl/ultix#<hostname>

nix-shell -p mkpasswd --run 'mkpasswd -m sha-512' | sudo tee /mnt/persist/passwords/fumoctl
```

## 16. Managing secrets with `sops-nix`

Secrets are encrypted using **SOPS** with a post-quantum hybrid Age master key (`mlkem768x25519`, `age1pq1...`).
- The persistent Age private key lives on disk at `/persist/sops/fumosops.key` (mode `0600`, owned by `fumoctl`).
- The public key recipient and matching path regexes are declared in `.sops.yaml`.
- The encrypted secrets file is `secrets/secrets.yaml`.
- `SOPS_AGE_KEY_FILE` is set to `/persist/sops/fumosops.key` in `home.sessionVariables` (`home/secrets.nix`).
- Secrets wiring, templates, and PGP auto-import are configured in `home/secrets.nix`.
- `systemd.user.services.sops-nix` has `ConditionPathExists = "/persist/sops/fumosops.key"`, so systems without this key build and activate cleanly while simply skipping secret decryption.

### Common workflows

#### 1. Edit secrets interactively in your editor
Opens `secrets/secrets.yaml` in `$EDITOR` (e.g. Neovim), decrypting it into a temporary buffer in memory. On save/quit (`:wq`), SOPS automatically re-encrypts the file and updates its MAC:
```bash
sops secrets/secrets.yaml
```

#### 2. Decrypt and re-encrypt in place (e.g. to edit in GUI editors like VSCodium)
If you want to view or edit the plaintext directly in an external editor:
```bash
# Decrypt in-place (turns ENC[...] into plaintext)
sops --decrypt --in-place secrets/secrets.yaml

# ... make your edits in VSCodium and save ...

# Re-encrypt in-place (re-encrypts values and recalculates MAC)
sops --encrypt --in-place secrets/secrets.yaml
```
> **IMPORTANT**: NEVER commit `secrets/secrets.yaml` while it is decrypted. Always inspect `git diff secrets/secrets.yaml` before committing to ensure all values show `ENC[AES256_GCM,...]`.

#### 3. View decrypted content in the terminal without modifying
```bash
sops --decrypt secrets/secrets.yaml
# Or inspect a single key:
sops --extract '["abacusai_api_key"]' secrets/secrets.yaml
```

#### 4. Adding a new secret

1. Open the file with `sops secrets/secrets.yaml` and add the new key:
   ```yaml
   my_new_token: super_secret_value
   ```
   Save and exit to encrypt it.

2. Declare the secret in `home/secrets.nix` under `sops.secrets`:
   ```nix
   sops.secrets."my_new_token" = {
     mode = "0600";
     # path = "${config.home.homeDirectory}/.config/my-app/token"; # optional target path
   };
   ```

3. Exposing it to programs:
   - **As an environment variable**: Add it to `sops.templates."shell-secrets.sh".content` in `home/secrets.nix`:
     ```nix
     sops.templates."shell-secrets.sh".content = ''
       export ABACUSAI_API_KEY="${config.sops.placeholder.abacusai_api_key}"
       export MY_NEW_TOKEN="${config.sops.placeholder.my_new_token}"
     '';
     ```
     *(This is automatically sourced by `programs.zsh.initContent` in `home/shell.nix`)*.
   - **As a file path**: Decrypted secret files are placed at `${config.sops.secrets."my_new_token".path}` (defaults to `~/.config/sops-nix/secrets/my_new_token`).

4. Stage and rebuild:
   ```bash
   git add secrets/secrets.yaml home/secrets.nix
   sudo nixos-rebuild switch --flake .#<hostname>
   ```

#### 5. Rotating or changing the Age master key
To add a new key recipient (or re-key the file after changing `.sops.yaml`):
```bash
# Update .sops.yaml with the new recipient public key, then re-wrap the data keys:
sops updatekeys secrets/secrets.yaml
```
